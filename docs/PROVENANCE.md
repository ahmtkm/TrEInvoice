# Provenance

TrEInvoice v0.1.0 does not bundle GİB tax catalogs.

TrEInvoice v0.1.0 does not redistribute GİB UBL-TR schemas.

TrEInvoice v0.1.0 does not bundle provider-derived tax or withholding datasets.

The repository contains no redistributed GİB XSD, tax catalog, provider dataset, or copied proprietary source. The UBL namespace identifiers in source describe the external XML vocabulary; no external schema files are included.

Test fixtures are synthetic and use fictional parties and values.

OASIS UBL is an external standard referenced by the project; this repository does not redistribute external schema files.

No official GİB compliance claim is made.

Library projects are licensed under MIT as shown in the repository LICENSE. Third-party package dependencies are limited to test tooling declared in test projects; the runtime libraries have no third-party package dependencies. Package repository metadata is intentionally not assigned until a canonical public repository URL exists.
